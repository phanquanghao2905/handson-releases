# HandsOn

HandsOn là ứng dụng Beta trải nghiệm nghề dầu khí, gồm xưởng bảo trì và phòng điều khiển khoan. Web chạy tại [handsonapp.pages.dev](https://handsonapp.pages.dev/).

Gói Windows, macOS và Android được phân phối dưới dạng tài sản đính kèm của GitHub Releases. Xem [Release notes](RELEASE-NOTES.md), [hướng dẫn cài đặt](INSTALL.md) và [SHA256SUMS.txt](SHA256SUMS.txt).
